## High-Level Summary

This project is a React + TypeScript control surface for live media teams who operate OBS Studio and ProPresenter together.

- Frontend runtime: React 19 + Vite + TanStack Router + TanStack Query
- Integrations:
  - OBS through WebSocket (`obs-websocket-js`)
  - ProPresenter through HTTP API polling and trigger endpoints
- Primary UI:
  - Unified dashboard at `/connect`
  - Public landing at `/`
  - Auth and recovery pages (`/sign-in`, `/sign-up`, `/forgot-password`, `/reset-password`)

## Important Implementation Notes

- `src/routeTree.gen.ts` is generated by TanStack Router CLI. Do not edit manually.
- Session/auth storage in `src/server/functions/auth.ts` is in-memory only and not persisted.
- `src/components/obs/committer.tsx` is currently a placeholder/debug file and is not used by app flows.
- `package.json` includes a typo in `clean` script path (`.ouptut` instead of `.output`).
